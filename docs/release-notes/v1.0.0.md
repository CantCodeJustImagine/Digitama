# TamaDigi v1.0.0

The first Digimon release, converted from the TamaPoke engine.

- 87 Digimon from Ver.1 to Ver.5, in full colour (Digimon Color sprites), with a Mega stage in every version
- Digivolution by the stage clock, branched by care mistakes, training and battles won
- Element chart plus the Vaccine > Virus > Data attribute triangle, 151 attacks
- Boss ladders per version, wild encounters by stage, scan chips, recovery disks
- Original music, badges, avatars and battle backgrounds; no Nintendo assets remain
- The installer is built and published by GitHub Actions (`pages.yml`)
